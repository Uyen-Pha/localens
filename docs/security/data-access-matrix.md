## Edge boundary checklist

- **corsAllowlist**: fail closed to checked-in production/demo origins; no wildcard with credentials
- **requestBodyLimit**: reject oversized JSON before parsing; separate public and internal limits
- **turnstile**: verify action and hostname server-side; fail closed on missing/invalid secret or response
- **secrets**: Edge environment secret store only; never NEXT_PUBLIC, static bundle, logs, audit, or client DTO
- **correlationRedaction**: allow correlation IDs only; redact tokens, signatures, IP/device hashes, payment payloads and PII
- **staticBundle**: scan output for service-role, Stripe, AI, HMAC and Turnstile secrets
- **credentialBoundary**: service_role and internal executor credentials are Edge-only and are not RLS evidence
